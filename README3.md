Person 3: MLlib Text Classification Commands
This guide assumes a standard Unix-like environment (macOS, Linux, or WSL) matching the project specifications (Python 3.11, PySpark 3.5.8) with no additional OS workarounds required.

Ensure the AG News dataset (train.csv) has been downloaded and placed in the part2/ directory before starting.

1. Train and Save the Pipeline Model
This script processes the AG News dataset, reports the class distribution, trains the MLlib pipeline strictly in the required stage order, and saves the PipelineModel for both batch and real-time use.


python part2/train_model.py \
  --input_data part2/train.csv \
  --model_path models/ag_news_model

  
2. Run Batch Classification
This command applies the saved model to the 1,000-message corpus generated by Part 1. It casts the probability vectors to strings for CSV compatibility and filters out empty live data. The output is used for the 50-message manual accuracy evaluation.


python part2/batch_classify.py \
  --input_file outputs/collected_messages.jsonl \
  --model_path models/ag_news_model \
  --output_file outputs/predictions.csv


3. Test Real-Time Classification Locally
This runs a standalone dummy stream to verify the streaming logic and CSV output behavior before it is integrated into the final application. It uses a dedicated checkpoint directory separate from the NER queries. Terminate the stream manually with Ctrl+C when testing is complete.


python part2/class_stream.py \
  --model_path models/ag_news_model \
  --checkpoint_dir checkpoints/classification_test \
  --output_csv outputs/class_counts.csv
